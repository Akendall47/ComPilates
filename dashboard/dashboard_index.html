How to Use This Dashboard
Task IDs — what is #T01?
Every task has an ID like #T01, #T12 etc. You use these in git commit messages to link your work to a task automatically.

Example: git commit -m "Add if/else codegen #T12 [2h]"

The dashboard will show that commit under T12, count the 2h towards its time total, and tag it as codegen and control-flow automatically.
Adding & Editing Tasks
From the dashboard (recommended): Go to the Task Board tab → click + New Task to add, or expand any task with ▸ and click Edit Task. Changes save instantly to AWS — no commit needed.

Tasks are stored in DynamoDB, not in any file in the repo. Both partners see changes immediately.
Time Tracking — auto vs manual
Auto (from git commits): Add a time tag to your commit message:
[2h] — 2 hours  ·  [45m] — 45 minutes  ·  [1h30m] — 1.5 hours  ·  [2.5h] — 2.5 hours

This time is parsed automatically on every push and linked to whichever task IDs appear in the same commit message.

Manual (logged_hours): Expand a task on the Task Board → click Edit Task → update the Logged Hours field. This is useful for time you forgot to log in a commit, or study/planning time with no commit.

Total time shown on the dashboard = logged_hours (manual) + time parsed from git commits.
Status badges
Click any status badge on the Task Board to cycle it: todo → progress → done → todo.
Or expand a task and use Edit Task for more control. Status saves instantly to AWS.
How the dashboard updates
Tasks (add/edit/status): update live immediately from this page — no push needed.

Git stats (commits, time from messages, contributor charts): updated automatically by GitHub Actions on every push to main. Takes ~30 seconds after a push.

The dashboard URL is: http://compilates-dashboard.s3-website.eu-north-1.amazonaws.com
Branches
Branches are auto-linked to tasks when the branch name contains a task ID:

git checkout -b feature/T01-parser
git checkout -b T12-codegen
git checkout -b fix/T06-stack-alignment

Use T01 (no #) in branch names — separators can be /, _, or -.

The Task Board shows a branch chip on each linked task. Status is automatic:
● merged — merged into main  ·  ● open — active  ·  ● stale — no commits in 14+ days

You can also manually set a branch name on a task via Edit Task → Branch field (useful for non-standard names).
Logging meetings
Go to the Meetings tab → click + Log Meeting.

Meeting ID — use sequential IDs like M001, M002 etc.
Duration — hours spent (counts towards total project time).
Agenda / Topic — what you planned to discuss.
Outcomes / Action Items — decisions made, next steps, who does what.

Meetings are stored in DynamoDB and visible to both partners immediately. Click Edit on any meeting card to update or delete it.
Commit message format (full reference)
git commit -m "description #T01 #T02 [2h]"

— Multiple task IDs are allowed; time is split equally between them
— Task ID and time tag are both optional; a commit with neither still appears in the log
— Time without a task ID is counted in overall totals but not linked to any task
